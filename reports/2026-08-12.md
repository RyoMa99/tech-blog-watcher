## BigQuery

### Feature

data clean rooms 向けのクエリテンプレートが一般提供(GA)になりました。クエリテンプレートを使うと、data clean room のオーナーおよびパブリッシャーは、基となるテーブルやビューを公開せずに定義済みクエリを共有できます。

## Compute Engine

### Feature

一般提供: G2・G4 GPU アクセラレータ最適化マシンシリーズ向けに Compute flexible committed use discounts(CUD)が利用可能になりました。対象リソースは vCPU、メモリ、Local SSD ディスク、GPU です。

Compute flexible CUD は、Compute Engine・GKE・Cloud Run にまたがる対象 Google Cloud 利用額に適用される支出ベースの CUD です。G2・G4 マシンシリーズでは、ワークロードの要件に応じて対象マシンシリーズやリージョンを柔軟に切り替えられます。これらのマシンシリーズに属する GPU については、compute flexible commitment に予約の紐付けは不要です。

詳細は Compute flexible CUDs を参照してください。

## Google Distributed Cloud (software only) for VMware

### Announcement

Google Distributed Cloud (software only) for VMware 1.35.400-gke.81 がダウンロード可能になりました。アップグレード方法は Upgrade clusters を参照してください。Google Distributed Cloud 1.35.400-gke.81 は Kubernetes v1.35.3-gke.400 上で動作します。

サードパーティのストレージベンダーを利用している場合は、検証済みストレージパートナーの一覧を確認してください。

リリース後、GKE On-Prem API クライアント(Google Cloud コンソール、gcloud CLI、Terraform)で当該バージョンが利用可能になるまで、通常7〜14日かかります。

### Fixed

1.35.400-gke.81 で以下の問題を修正しました。

- 本リリースで対応したセキュリティ脆弱性の一覧は Vulnerability fixes へのリンクを参照してください。

- 管理クラスタのアップグレード後、ユーザークラスタが Reconciling 状態のまま止まってしまう問題を修正しました。従来、管理クラスタコントローラは初期移行アノテーションが設定されていない限り、アップグレード中にレガシーのクラスタライフサイクルコンポーネントの調整をスキップしていました。管理クラスタ上にレガシーのユーザークラスタが残っている場合、レガシー API ディスカバリ(cluster.k8s.io/v1alpha1)が欠落し、コントローラの調整処理が停止していました。この修正により、レガシーのユーザークラスタが1つでも存在する限りコントローラはレガシーコンポーネントを維持し、すべてのユーザークラスタが advanced cluster への移行を終えた後にのみそれらを削除するようになりました。

- プライベートコンテナレジストリへの認証時に gkectl prepare が permission denied エラーで失敗する問題を修正しました。

- advanced cluster へのユーザー/管理クラスタのアップグレードを再試行すると etcd シークレットの復号に失敗する問題を修正しました。
