## Cloud Hub

### アナウンス

2026年9月15日より、App Topology API は使用量ベースの課金モデルに移行します(1日あたりの無料データ使用枠あり)。詳細は App Topology の料金ページを参照してください。

## Cloud Run functions

### 新機能

Cloud Run functions のアップグレードツールが一般提供(GA)になりました。このツールを使うと第1世代のFunctionsをCloud Run functionsにアップグレードできます。

## Eventarc

### 変更点

Cloud Run(Cloud Run functionsを含む)宛てのEventarcトリガーを設定する際、リトライなしの単発配信を指定できるようになりました。詳細はCloud Run宛先のリトライに関するページを参照してください。

## Gemini

### その他

### VS Codeのバグ修正

各種バグ修正と細かな機能改善。

## Gemini Enterprise

### 新機能

Gemini Enterprise: ユーザーデータをCSVファイルにエクスポート

Gemini Enterpriseの管理者は、ユーザーデータをCSV(カンマ区切り値)ファイルにエクスポートし、オフラインでソート・フィルタ・分析できるようになりました。この機能は一般提供(GA)です。

詳細はユーザーデータのエクスポートに関するページを参照してください。

## Memorystore for Valkey

### 新機能

Google Cloud コンソールから、基本的なトークンベース認証を使ってインスタンスへのアクセスを保護できるようになりました。この機能はプレビュー提供です。

## Security Command Center

### 新機能

Security Command Center と Application Design Center の統合により、アプリケーションライフサイクル全体のセキュリティ評価が一般提供(GA)になりました。設計時点での検出結果はデプロイ時にオンデマンドでSecurity Command Centerへ送信されます。この機能により、App Hub対応のフォルダ・プロジェクト単位でアプリケーションごとに検出結果をフィルタできます。

詳細はアプリケーションライフサイクルのセキュリティ評価に関するページを参照してください。

### 新機能

Google Cloud向けVulnerability Assessmentが一般提供(GA)になりました。
